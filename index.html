Floyd–Warshall: All-Pairs Shortest Path

Floyd–Warshall finds the shortest path between every pair of vertices in a weighted graph. Unlike Dijkstra's, it handles negative edge weights (but not negative cycles).

dist[i][j] = min( dist[i][j], dist[i][k] + dist[k][j] )

For each intermediate vertex k, we check: "Is it cheaper to go from i to j by passing through k?"
