Dynamic Programming · O(V³)

Floyd–Warshall Algorithm

Computes the shortest path between every pair of nodes in a weighted directed graph — in a single run. Works with negative edge weights (but not negative cycles).

dist[i][j] = min( dist[i][j], dist[i][k] + dist[k][j] )
